# Linux System Info Tool

A simple, lightweight Bash tool to display essential system information on Linux machines.

## Features
- Display CPU information
- Show memory usage
- List disk space
- Check network interfaces
- Show running processes
- Display system uptime

## Installation

### Clone the repository
```bash
git clone https://github.com/bakeery-dev/linux-system-info-tool.git
cd linux-system-info-tool
```

### Make the script executable
```bash
chmod +x system_info.sh
```

## Usage
Run the script with:
```bash
sudo ./system_info.sh
```

**Note:** Some features require root privileges for accurate information.

## Requirements
- Bash 4.0+
- Linux-based operating system
